RESTORING THE REPOSITORY
------------------------
  git clone gavel.bundle GAVEL
  cd GAVEL
  bun install
  cp .env.example .env            # then set a real AUTH_SECRET for anything
                                  # beyond local dev
  bun run db:push                 # create SQLite schema
  bun run seed:dev                # demo tenant, findings, invoices
  bun run dev                     # http://localhost:3000

PUSHING TO GITHUB
-----------------
The GitHub remote (VampFay/GAVEL) is NOT updated in this package. To push:
issue a fresh PAT (Contents RW + Workflows RW + Metadata RO), then
  GAVEL_GH_TOKEN=<token> bash scripts/push-github.sh
Never commit or echo the token. Revoke the old token if not already done.

WHAT GAVEL DOES
---------------
GAVEL cross-examines your SOW, your delivery evidence (Jira/GitHub) and your
invoices — then issues a verdict on every billed dollar. It reconciles
milestones, change orders, effort caps and invoice lines into reviewable
findings with immutable audit logging.
